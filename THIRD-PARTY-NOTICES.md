## Where the third-party code sits

The requirements exchange's four ready-made sites, `demos/requirements-exchange/sites/1.0-original/`,
`sites/1.0/`, `sites/1.1-unconfirmed/` and `sites/1.1-confirmed/`, are Sphinx's HTML output. Each
holds the same `_static/` folder, built with the versions `demos/requirements-exchange/team/requirements.txt`
pins (Sphinx 9.0.4, sphinx-needs 9.2.0) and the packages they install:

| Component | Version | Licence | Files in each site's `_static/` |
|---|---|---|---|
| Sphinx | 9.0.4 | BSD-2-Clause | `basic.css`, `doctools.js`, `documentation_options.js`, `language_data.js`, `searchtools.js`, `sphinx_highlight.js`, `graphviz.css`, `file.png`, `minus.png`, `plus.png`, and `_sphinx_javascript_frameworks_compat.js` (which reaches the site through sphinxcontrib-jquery 4.1; its header names the Sphinx contributors and the two-clause BSD licence); the pages' scaffolding around the requirements (`genindex.html`, `search.html`, `searchindex.js`) is Sphinx's template output |
| Snowball stemmers | 3.0.1 | BSD-3-Clause | `base-stemmer.js`, `english-stemmer.js` (generated by Snowball 3.0.1 and shipped with Sphinx) |
| Pygments | 2.21.0 | BSD-2-Clause | `pygments.css` (generated from Pygments' style) |
| alabaster | 1.0.0 | BSD-3-Clause | `alabaster.css`, `custom.css`, `github-banner.svg` |
| jQuery | 3.6.0 | MIT | `jquery.js` (shipped with sphinxcontrib-jquery 4.1) |
| sphinx-needs | 9.2.0 | MIT | `sphinx-needs/` |
| sphinx-data-viewer | 0.1.5 | MIT | `sphinx-data-viewer/` |

The requirements exchange's presentation, `demos/requirements-exchange-presentation.html` and its public
copy `demos/requirements-exchange-presentation-public.html`, are Marp's HTML output and inline Marp's
runtime and its default theme:

| Component | Version | Licence | Where |
|---|---|---|---|
| Marp CLI (`@marp-team/marp-cli`) | 4.4.1 | MIT | the inline viewer script, which also bundles bespoke 1.2.0-dev (MIT) and vhtml 2.2.0 (MIT), as its header's licence file lists |
| Marp Core (`@marp-team/marp-core`) | 4.3.1 | MIT | the inline default theme |
